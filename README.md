# OreoPie

A fast, secure and modern peer-to-peer file sharing platform built with React + Vite.

## Features

- Fast P2P file transfer
- Multi-device support
- Secure sharing
- Responsive UI

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Supabase

## Installation

npm install

npm run dev

## Build

npm run build
